# ksuzuki_app_01
トライアル的なリポジトリ（小さなアプリを試しに作る「練習箱」）

## アプリ一覧
アプリごとにフォルダを分けています。一番上の `index.html` は、各アプリへのリンクを並べたメニュー画面です。

| フォルダ | アプリ | 内容 |
| --- | --- | --- |
| `memo/` | 📝 かんたんメモ帳 | メモを書いて保存・編集・削除 |
| `score/` | ⚾ チーム成績 | 「成績を見る」（メンバー向け）と「記録する」（スコア入力）を1つにまとめたアプリ |
| `eitango/` | 📖 えいたんご | 中学レベルの英単語・熟語をクイズやカードで覚える（**別のサイトで公開**。下の説明を参照） |
| `results/` | （移動のお知らせ） | 前の成績ページのURL。開くと `score/` の「成績を見る」に自動で移動します |

公開先：Netlify（GitHub の main ブランチと連携して自動で公開。設定は `netlify.toml`）
- チーム成績・メモ帳：neighbors-softball のサイト（一番上の `netlify.toml`）。`/eitango/` はこのサイトでは開けないようにしています
- えいたんご：別のサイト（`eitango/netlify.toml`）

## 各アプリのファイルの役割
| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の「骨組み」 |
| `style.css` | 画面の「見た目」 |
| `app.js` | 画面の「動き」 |

## チーム成績（score/）の使い方

### 成績を見る（メンバー）
- 試合結果・シーズン・通算の成績を見られます（公開されている `score/data.json` を表示）
- シーズン・通算は、打率順・本塁打順などに並べ替えられます

### 記録する（記録係・代理の人）
1. 「選手」タブで選手を登録する（選手が空のときは、公開中の成績から自動で読み込みます）
2. 「試合入力」タブで「＋新しい試合」を押し、日付と対戦相手を入れる
3. 「オーダー」タブで打順ごとに先発を選ぶ（1番〜最大15番。前の試合の先発を引き継ぎます）
   - 別の打順に入っている選手を選ぶと、その選手が移り、元の打順は（未設定）になります
4. 「◀ ▶」で回を選び、結果・打点を選んで「記録する」を押す（次の打順に自動で進みます）
5. 代打は打者の横の「代打」、または「オーダー」タブの「代打・交代」。退場は「オーダー」タブの「退場」
6. 得点・盗塁は、スコアシートの記録をタップして後から付ける（本塁打は自動で得点）

記録は、そのスマホのブラウザの中に保存されます。

### 成績を公開する（記録係）
1. 「データ」タブで「公開用ファイル（data.json）を書き出す」
2. GitHub で `score` フォルダを開き、「Add file」→「Upload files」で `data.json` をアップロードして「Commit changes」
3. 1〜2分で Netlify が自動で公開し直し、「成績を見る」が新しくなる

### 代理で記録する（記録係がいない日）
1. 代理の人は、同じURLを開いて「記録する」へ。選手データとオーダーは、公開中の成績から自動で読み込まれます
2. 試合を記録したら、「データ」タブの「この試合を書き出す」で、記録係に送る
3. 記録係は「データ」タブの「試合のファイルを選ぶ」で取り込む（今の記録に追加されます）
   - 記録係のスマホにいない選手は、「誰と同じ人か」「新しい選手か」を選べます

### シーズン
- 4月〜翌3月を1シーズン（年度）として集計します。試合を作ると、日付から自動で選ばれます
- 前の年度の試合が後にずれこんだときは、試合を作るとき（または「試合情報を変更」）にシーズンを変えられます

### 過去の成績（2018〜2024年度）
- Excelの記録を変換したファイルを、「データ」タブ →「過去の成績を取り込む」で取り込みます（今の記録はそのまま）
- 選手は「名前」でつながります。今のメンバーは、Excelと同じ名前で「選手」タブに登録してください
- 2018年度は一部がシーズン合計のみ、2019〜2024年度は試合ごとの合計があります（回ごとの記録はありません）
- 出塁率は、Excelの記録に合わせて犠打も割る数に入れて計算しています（2025年度以降の記録は犠飛のみ）

## えいたんご（eitango/）の使い方

### 公開のしかた（別のサイトにする）
同じリポジトリから、Netlify にもう1つサイトを作ります。
1. Netlify で「Add new project」→「Import an existing project」→ GitHub → このリポジトリを選ぶ
2. Branch to deploy は `main`、**Base directory は `eitango`**、Build command と Publish directory は空のまま
3. 「Deploy」のあと、「Project configuration」→「Change project name」でサイト名を変える
4. `https://＜サイト名＞.netlify.app/` で、えいたんごが直接開きます

| ファイル | 役割 |
| --- | --- |
| `eitango/words.js` | 英単語のデータ（中1〜中3） |
| `eitango/idioms.js` | 熟語のデータ（例文つき） |

### 使う人とモード
- 最初の画面で「だれが勉強するか」を選びます（2人ぶん。名前・アイコン・モードは「設定」で変えられます）
- **中学生モード**：中1〜中3の単語・熟語。学年（中1／中2／中3／ぜんぶ）と種類（単語／熟語／両方）を選んで練習します
- **小学生モード**：中1の単語のうち絵文字のあるものを、絵とひらがなで覚えます

### 遊び方
| 遊び方 | 内容 |
| --- | --- |
| 今日の復習 | 復習の日が来た単語と新しい単語を、問題の形をまぜて10問 |
| カードで覚える | カードをめくって意味を確認し、「覚えた／まだ」を選ぶ |
| 英語→意味／意味→英語 | 4つから選ぶ |
| 聞いて選ぶ | 読み上げを聞いて選ぶ（小学生モードは絵で選ぶ） |
| スペルを書く | 意味を見て英語を入力（小学生モードは文字のタイルを並べる） |
| 熟語の穴うめ | 熟語の空らんに入る語を選ぶ（中学生モードのみ） |
| 例文ならべかえ | 熟語の例文を、単語をタップして並べる（中学生モードのみ） |
| にがてを練習 | まちがえたことのある単語だけを練習 |

### 覚え具合のしくみ
- 正解するたびにレベルが上がり、次に出てくるまでの日数がのびます（1日 → 3日 → 7日 → 14日 → 30日）
- まちがえるとレベル0に戻り、次の日の「今日の復習」にまた出てきます。その回の最後にも、もう一度出ます
- レベル3以上（3回続けて正解）を「覚えた」として、「記録」に学年ごとの覚えた数を表示します

### 単語を増やすとき
- `words.js` に「英語|意味|絵文字」の1行を足すだけで出題されます（絵文字はなくてもOK）
- `idioms.js` は「熟語|意味|例文|例文の訳」。熟語の中の `[ ]` でかこんだ語が穴うめの空らんになります
- 読み上げはスマホに入っている英語の音声を使います（音声ファイルは不要）

## 注意
- 公開した成績は、URLを知っている人なら誰でも見られます。
- 記録はそのスマホ・そのブラウザの中だけに保存されます。ブラウザのデータを消すと記録も消えるので、ときどき「データ」タブでバックアップしてください。
