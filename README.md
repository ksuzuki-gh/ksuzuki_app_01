# ksuzuki_app_01
トライアル的なリポジトリ（小さなアプリを試しに作る「練習箱」）

## アプリ一覧
アプリごとにフォルダを分けています。一番上の `index.html` は、各アプリへのリンクを並べたメニュー画面です。

| フォルダ | アプリ | 内容 |
| --- | --- | --- |
| `memo/` | 📝 かんたんメモ帳 | メモを書いて保存・編集・削除 |
| `score/` | ⚾ 打撃成績スコアシート | ソフトボールの打撃結果を記録し、打率などを自動計算 |

GitHub Pages で公開した場合のURL：
- メニュー：`https://ksuzuki-gh.github.io/ksuzuki_app_01/`
- メモ帳：`https://ksuzuki-gh.github.io/ksuzuki_app_01/memo/`
- スコアシート：`https://ksuzuki-gh.github.io/ksuzuki_app_01/score/`

## 各アプリのファイルの役割
| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の「骨組み」 |
| `style.css` | 画面の「見た目」 |
| `app.js` | 画面の「動き」 |

## 打撃成績スコアシートの使い方
1. 「選手」タブで選手を登録する（控えの選手も登録しておくと、代打に使えます）
2. 「試合入力」タブで「＋新しい試合」を押し、日付と対戦相手を入れる
3. 「オーダー」タブで、打順ごとに先発の選手を選ぶ（1番〜最大15番。前の試合の先発を引き継ぎます）
4. 「試合入力」タブで、「◀ ▶」で回を選び、結果・打点を選んで「記録する」を押す（次の打順に自動で進みます）
5. 代打は、打者の横の「代打」ボタン、または「オーダー」タブの「代打・交代」で入れる
6. 退場は「オーダー」タブの「退場」で記録する（空いた打順は飛ばされます。代わりの選手は「代打・交代」で入れられます）
7. 得点・盗塁は、スコアシートの記録をタップして後から付ける（本塁打は自動で得点）
8. 「成績」タブで打率・出塁率・OPS・得点・盗塁などを確認する
9. 「データ」タブで記録をファイルに書き出しておくと、機種変更のときも引き継げる

## 注意
- データはそのスマホ・そのブラウザの中だけに保存されます。別の端末とは共有されません。
- ブラウザの履歴やデータを消すと、記録も消えます。
