# ksuzuki_app_01
トライアル的なリポジトリ

## 📝 かんたんメモ帳

スマホのブラウザで使える、シンプルなメモ帳アプリです。

### できること
- メモを書いて保存する
- 保存したメモを編集する・削除する
- ページを閉じてもメモは残る（使っているブラウザの中に保存されます）

### ファイルの役割
| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の「骨組み」（入力欄・ボタン・一覧の場所） |
| `style.css` | 画面の「見た目」（色・大きさ・並び方） |
| `app.js` | 画面の「動き」（保存・編集・削除の処理） |

### 注意
- メモはそのスマホ・そのブラウザの中だけに保存されます。別の端末とは共有されません。
- ブラウザの履歴やデータを消すと、メモも消えます。
