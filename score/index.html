    今の記録

    成績をチームに公開する（記録係）

    「成績を見る」の画面に、最新の記録をのせるためのファイルを作ります。

    1. 上のボタンで data.json を書き出し、スマホの「ファイル」アプリなどに保存する
    2. GitHub でリポジトリを開き、score フォルダを開く
    3. 「Add file」→「Upload files」を押し、data.json を選ぶ
    4. 一番下の緑の「Commit changes」を押す
    5. 1〜2分すると、Netlify が自動で公開し直し、「成績を見る」が新しい記録に変わる

    ファイル名は data.json のままにしてください。名前が違うと読み込めません

    代理で記録した試合を送る（代理の人）

    記録係がいない日に代わりに記録したときは、その試合だけをファイルにして記録係に送ります。

    代理で記録された試合を取り込む（記録係）

    代理の人から送られてきた試合のファイルを、今の記録に追加します。今の記録は消えません。

    知らない選手が入っていたときは、取り込む前に「誰と同じ人か」「新しい選手か」を選べます

    記録を書き出す（バックアップ）

    選手・試合・打席のすべての記録を、1つのファイルにまとめます。

    ファイルから読み込む

    書き出したファイルを選ぶと、記録が元に戻ります。
    今このスマホにある記録は、ファイルの中身に置き換わります。

    過去の成績を取り込む

    Excelの記録から変換した過去の成績のファイルを取り込みます。今の記録はそのまま残り、成績の「シーズン」「通算」に合計されます。

    スマホを替えるときの手順

    1. 古いスマホで「ファイルに書き出す」を押す
    2. 出てきたメニューから、メールや LINE の自分あて、iCloud Drive、Google ドライブなどに送る
    3. 新しいスマホでそのファイルを受け取り、「ファイル」アプリなどに保存する
    4. 新しいスマホでこのアプリを開き、「ファイルを選んで読み込む」でそのファイルを選ぶ

    スマホを替える予定がなくても、ときどき書き出しておくと安心です
